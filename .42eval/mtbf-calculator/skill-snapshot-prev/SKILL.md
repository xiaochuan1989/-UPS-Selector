采用 **MIL-HDBK-217F Notice 2 零件计数法**，对话采集配置后输出专家级可靠性预计报告（Word 文档，含页眉/页脚/封面/双子系统计算表/结论/附录）。

## 计算方法：MIL-HDBK-217F 零件计数法

### 基本公式

```
λ_sys = Σ (Ni × λ_Gi × πQi)
MTBF  = 1 / λ_sys
```

- 环境类别：GF（地面固定），πE = 1.0，温度基准 40°C
- 计算精度：±20%（零件计数法，设计阶段预计）

### 子系统划分

**子系统一（配电）**：输入保护 + 输出保护 + 防雷器 + 母排 + 端子 + 内部线缆

**子系统二（监控）**：HMI + 主控板 + 导轨电源 + IMD（可选）+ 传感器 + 继电器 + LED + 线缆

## 元器件失效率数据（GF环境，40°C）

### 配电器件（MIL-HDBK-217F 查表值）

| 元器件 | Section | λ_G (×10⁻⁶/h) | πQ（工业级） | 单件λ | 备注 |
|--------|---------|--------------|------------|------|------|
| 低压熔断器 | 12 | 0.0100 | 2.0 | **0.0200** | |
| 微型断路器 MCB（2P/4P） | 11 | 0.0100 | 2.0 | **0.0200** | |
| MOV 防雷器 | 26 | 0.0030 | 2.0 | **0.0060** | |
| 铜排/母排 | 17 | 0.0010 | **1.0** | **0.0010** | 纯导体，πQ固定1.0 |
| 接插件/端子 | 15 | 0.0027 | 2.0 | **0.0054** | 每路一个 |
| 内部线缆（整柜） | 经验 | — | — | **0.200/套** | 固定估算值 |

**端子数量计算规则：**
- 输入端子 = 输入路数（每路输入一个大电流端子）
- 输出端子 = 输出路数（每路输出一个中小电流端子）
- 例：2路输入 + 60路输出 → 端子贡献 = (2 + 60) × 0.0054 = 0.3348 ×10⁻⁶/h

### 监控器件

| 组件 | 参考 MTBF | λ (×10⁻⁶/h) | πQ | 备注 |
|------|---------|------------|-----|------|
| 7寸工业 HMI | 300,000 h | **3.3333** | — | 威纶通/昆仑通态 |
| 10寸工业 HMI | 250,000 h | **4.0000** | — | 大屏背光略低 |
| 监控主控板 | 800,000 h | **1.2500** | — | Sec.5/9/10 估算 |
| DIN 导轨电源 | 2,000,000 h | **0.5000** | — | MEAN WELL Telcordia |
| 直流绝缘监测 IMD | 600,000 h | **1.6667** | — | 工业级典型值 |
| 霍尔传感器 | λ_G=0.0100 | 0.0200/个（工业）<br>0.0150/个（进口） | 随等级¹ | Sec.5 |
| 小型密封继电器 | λ_G=0.0400 | 0.0800/个（工业）<br>0.0600/个（进口） | 随等级¹ | Sec.13 |
| LED 指示灯 | λ_G=0.0100 | 0.0150/个 | **固定 1.5** | Sec.6，πQ不随等级变 |
| 监控线缆/PCB | 经验 | — | — | **0.300/套** | 固定估算值 |

¹ 霍尔传感器/继电器 πQ 随 `component_grade` 变化：国产工业级=2.0，进口工业级=1.5，军品级=1.0。

### 器件等级 → πQ 对照

| component_grade 值 | πQ | 说明 |
|--------------------|----|------|
| `国产工业级`（默认） | 2.0 | CCC/CE/GB 认证 |
| `进口工业级` / `进口品牌` | 1.5 | 进口工业认证品 |
| `军品级` / `mil` | 1.0 | MIL-STD-883 认证 |

## 专家级输出质量检查

生成文档前自检：

- [ ] 结论表"技术要求"λ列 = `1e6 / mtbf_requirement_h`（动态计算，非固定10）
- [ ] 裕量百分比正确 = `(mtbf - req) / req × 100%`
- [ ] 混合输出时，SS1 表格有多行输出保护（每组一行）
- [ ] 进口器件 πQ=1.5，不能用默认的2.0
- [ ] 每行 λ_G 有 MIL-HDBK-217F Section 标注
- [ ] 文档有页眉（左：产品名，右：文件编号）和页脚（第X页/共Y页）

## 常见问题处理

| 场景 | 处理 |
|------|------|
| 用户提供图片配置 | 从图中提取参数，说明提取内容，请确认 |
| 无 BOM | 用零件计数法+典型配置估算，注明精度±20% |
| MTBF 不达标 | 分析主要失效源，建议：①升级HMI规格；②电源冗余；③选高可靠IMD |
| 要求非100,000h | 在 config 设 `mtbf_requirement_h`，λ上限和结论自动跟随 |
| 混合输出规格 | 用 `output_config.groups` 数组，每组独立一行 |
| 进口品牌器件 | 设 `component_grade: "进口工业级"`，πQ 自动取 1.5 |
| 需要 Excel 版 | 在对话中输出 Markdown 计算表，用户复制到 Excel |
