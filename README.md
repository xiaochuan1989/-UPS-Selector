# UPS 智能选型助手

**版本**: v1.5
**更新日期**: 2026-03-24

## 项目简介

UPS智能选型助手是一款面向销售和技术人员的本地Web工具，支持粘贴客户需求后由AI自动匹配UPS产品型号。单文件架构，无需安装，双击即可运行。

**线上地址**: https://xiaochuan1989.github.io/-UPS-Selector/

## v1.5 新增功能

1. **电池架功能** - 项目汇总清单新增电池架项，含铜排/电缆选项
2. **电池开关选项** - 合资/国产开关选择，品牌提示图标
3. **序号列** - 汇总清单添加序号列，导出Excel同步显示
4. **样式优化** - 类别换行、备注边框、导出Excel完整样式

## v1.4 新增功能

1. **UPS与电池配置计算** - 统一参数输入，一键计算电池推荐+电池开关箱/柜+电池监控
2. **电池计算(方法一/锂电)** - 独立界面，支持铅酸电池方法一和锂电池计算
3. **项目配置汇总清单** - 整合UPS+电池+开关箱+监控的完整配置表
4. **价格密码保护** - 汇总表价格显示需输入密码（314159）才能查看
5. **电池开关箱/柜** - 名称从"开关盒"改为"电池开关箱/柜"，描述包含分开关路数

## 开发注意事项

### 核心教训（v1.4）

| 错误类型 | 说明 | 预防措施 |
|----------|------|----------|
| 数据结构错误 | 凭猜测假设函数返回值 | 调用前确认返回值结构 |
| 变量名拼写 | BREAKER vs BREAKERS | 复制代码后检查一致性 |
| 常量重复定义 | 同名常量多处定义 | 添加前搜索是否已存在 |
| const不提升 | 函数调用时常量未定义 | 理解JS变量提升规则 |
| 修改不完整 | 只改一处遗漏关联位置 | 检查所有渲染/导出位置 |
| **业务逻辑理解错误** | **凭自己假设公式，不问用户** | **先搞清楚"应该是什么"，再动手** |
| **不主动询问** | **不确定时不问，直接猜** | **遇到业务问题，先问正确规则** |
| **验证走过场** | **只读代码不验证业务** | **让用户确认或提供原始公式** |
| **⚠️ 组件遗漏** | **修改配置时漏掉组件** | **对照参考实现，逐项核对组件清单** |

### ⚠️ 重要教训：传感器量程选择（v1.4.2-v1.4.6）

**问题描述**：修复传感器量程选择时，连续5次改错，浪费大量时间。

**根本原因**：
1. 没有理解业务逻辑就动手改代码
2. 凭自己假设"单组正常工作电流"，实际应该是"分开关电流"
3. 用户说"还是错的"时继续猜测，而不是停下来问清楚

**正确做法**：
```
❌ 错误：凭理解直接改代码，改了5次才对
✓ 正确：先问"传感器量程的选择依据是什么？公式是什么？"
```

### 开发流程

1. **激活 Serena MCP** - 每次优化前先激活
2. **搜索优先** - 修改代码前先搜索相关定义
3. **结构确认** - 调用函数前确认返回值结构
4. **完整性检查** - 修改后检查所有关联位置
5. **测试验证** - 刷新页面测试所有按钮
6. **⚠️ 业务逻辑确认** - 涉及公式/计算时，先问用户正确规则
7. **⚠️ 组件清单核对** - 修改配置类代码时，对照参考实现逐项核对

### ⚠️ 重要教训：组件遗漏（v1.4.7）

**问题描述**：`calcAllBatteryConfig` 函数中缺少测试线缆配置。

**根本原因**：
1. 没有列出"监控配置应该包含哪些组件"
2. 没有对照已有的 `calcMonitorConfig` 函数逐项核对
3. 只关注修复传感器问题，没检查整个配置

**正确做法**：
```
❌ 错误：直接改代码，想到什么写什么
✓ 正确：先列组件清单，对照参考实现逐项核对
```
