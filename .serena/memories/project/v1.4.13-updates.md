# v1.4.13 版本更新记录

（更新日期：2026-03-24）

## 主要变更

### 新增电池架功能

**功能说明**：
- 项目汇总清单新增"电池架"行
- 电池架容量 = 电池节数（cellsPerGroup）
- 电池架数量 = 电池组数 × UPS台数 = totalGroups
- 支持选择"是否含连接铜排/电缆"

**界面位置**：
统一计算面板 → 电池架含铜排/电缆 选项

**描述格式**：
- 不含铜排：`安装32节/架，电池型号：12V100AH`
- 含铜排：`安装32节/架，电池型号：12V100AH，含100A连接铜排或电缆`

**铜排电流规格**：
- 来自分开关电流对应的标准断路器规格（subSwitchSize）
- 例如：分开关电流95A → 选大一号规格100A

### 代码修改

| 文件 | 函数/区域 | 修改内容 |
|------|----------|----------|
| *.html | 统一计算面板UI | 新增"电池架含铜排/电缆"下拉选项 |
| *.html | projectSummary初始化（3处） | 添加batteryRack字段 |
| *.html | calcAllBatteryConfig() | 获取rackCable选项，计算电池架数据 |
| *.html | renderProjectSummary() | 渲染电池架行（粉色背景） |

### 数据结构

```javascript
window.projectSummary.batteryRack = {
  cellsPerRack: 0,       // 每架安装节数 = cellsPerGroup
  batteryModel: '',      // 电池型号（来自推荐或用户输入）
  includeCable: false,   // 是否含连接铜排/电缆
  cableAmp: '',          // 铜排电流规格（如"100A"）
  qty: 0,                // 数量 = totalGroups
  price: 0,
  note: ''
}
```

## 业务知识

### 电池架计算规则
- 电池架容量：根据电池组配置的节数决定
- 电池架数量：每电池组配一个电池架
- 连接铜排：选择"含"时，描述中体现电流规格

### 示例
- 配置：2台UPS，每台3组电池，32节/组
- 电池架数量 = 3 × 2 = 6架
- 描述：安装32节/架，电池型号：12V100AH，含100A连接铜排或电缆
