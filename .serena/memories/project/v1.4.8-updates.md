# v1.4.8 版本更新记录

（更新日期：2026-03-21）

## 主要变更

### 1. 电压等级公式优化
**旧公式**：基于电池节数判断
```
≤20节 → 250VDC
21~36节 → 500VDC
>36节 → 750VDC
```

**新公式**：基于最大充电电压判断
```
最大充电电压 = 2.35V × 单格数 × 电池节数
- 2V电池：单格数 = 1
- 12V电池：单格数 = 6

≤250V → 250VDC
251~500V → 500VDC
>500V → 750VDC
```

**代码位置**：
- `getVoltLevel(cells, battType)` 函数（~2685行）
- 返回值：`{ level, levelNum, maxChargeVoltage }`

### 2. 新增 UPS 中性线选项
- 输入参数：`<select id="unified-neutral">` （是/无）
- 存储位置：`switchBox.neutralLine`
- 显示：开关箱描述中显示"UPS带中性线"或"UPS无中性线"
- 提示：备注中添加⚠️重要提示

### 3. 项目汇总清单修复
- 表头添加"备注"列
- colspan 数值修正（8→9）

### 4. 术语调整
- "从控模块" → "单体测量模块"

## 教训记录

### 函数返回值解构错误
**问题**：`getVoltLevel()` 返回对象，但调用处直接当字符串使用
**现象**：显示 `[object Object]`
**修复**：正确解构 `const { level } = getVoltLevel(...)` 或分两行

### 多文件同步
每次修改必须同步 `UPS选型助手.html` 和 `index.html` 两个文件。
