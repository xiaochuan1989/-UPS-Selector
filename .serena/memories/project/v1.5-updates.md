# v1.6 开发更新记录

（已更新：2026-04-01 v1.6）

## v1.6 (2026-04-01)

### 新增功能

#### 1. 选型历史记录
- **功能**：保存每次AI选型的输入和结果
- **存储**：`localStorage["ups_selection_history"]`
- **限制**：最多50条，超出自动清理最早记录
- **功能**：
  - 搜索过滤（按需求文本/推荐型号）
  - 数量限制（10/20/50条）
  - 导出Excel
  - 恢复历史选型结果
- **UI入口**：顶部工具栏"📋 历史"按钮

#### 2. 图片OCR识别
- **功能**：粘贴技术文档截图，AI识别文字填入需求框
- **实现**：调用支持视觉的AI模型（kimi2.5/Claude3/GPT-4V）
- **粘贴方式**：全局Ctrl+V捕获，支持拖拽
- **API修改**：`callAI(userMessage, systemPrompt, images)` 支持图片参数

#### 3. Excel导出行高自适应
- **问题**：分析内容列显示不全
- **解决**：根据内容长度动态计算行高

### 技术细节

#### localStorage数据结构
```javascript
{
  version: 1,
  records: [{
    id: "uuid-timestamp",
    timestamp: "2026-04-01 10:30:00",
    requirement: "客户需求文本",
    analysis: "AI分析内容",
    recommended: [{model, reason}],
    also_consider: [{model, reason}],
    projectSummary: {...}
  }]
}
```

#### 核心函数
| 函数 | 位置 | 功能 |
|------|------|------|
| `saveSelectionHistory` | ~第1025行 | 保存历史 |
| `loadSelectionHistoryRaw` | ~第29892行 | 加载数据 |
| `getFilteredHistory` | ~第29905行 | 搜索过滤 |
| `restoreHistory` | ~第29930行 | 恢复历史 |
| `exportHistory` | ~第30025行 | 导出Excel |
| `extractTextFromImages` | ~第1697行 | AI图片识别 |
