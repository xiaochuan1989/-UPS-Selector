# v1.4.9 版本更新记录

（更新日期：2026-03-23）

## 主要变更

### 1. 新增 UPS型号自动填入功能（支持AI推荐 + 手动输入）

**功能位置**：电池配置面板 → 参数输入区 → UPS型号输入框

**输入方式**：
1. **下拉选择**：AI推荐型号 + 全部产品型号（共179款）
2. **手动输入**：直接输入任意型号，点击"填入参数"

**自动填入内容**：
- UPS容量(kVA)：从产品描述中提取
- 功率因数：从产品数据获取

**用户体验**：
- 使用 HTML5 datalist 实现"可输入可下拉"
- AI推荐型号优先显示在列表顶部
- 选择/输入后显示确认信息（型号、系列、容量、功率因数）

### 2. 界面元素

```
⚡ UPS型号: [输入框（可下拉）] [填入参数] ✓ UR-200KVA 太行UR | 200kVA / PF:0.9
```
