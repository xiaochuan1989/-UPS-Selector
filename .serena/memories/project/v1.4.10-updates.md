# v1.4.10 版本更新记录

（更新日期：2026-03-23）

## 主要变更

### 1. UPS型号汇总清单集成

**功能说明**：
- 用户选择的UPS型号自动保存到项目配置汇总清单
- 汇总清单现在包含完整的配置：
  1. **UPS主机** - 型号、系列、容量、台数
  2. **电池组** - 型号、规格、数量
  3. **电池开关箱/柜** - 电压等级、开关规格、数量
  4. **电池监控** - 主机、传感器、模块等

### 2. 代码修改
