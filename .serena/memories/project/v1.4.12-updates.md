# v1.4.12 版本更新记录

（更新日期：2026-03-23）

## 主要变更

### 1. 新增非标UPS支持

**功能说明**：
- UPS配置面板添加"标准/非标"切换
- 非标模式：手动输入型号和描述
- 非标UPS支持电池配置计算

**界面效果**：
```
[○ 标准  ● 非标]

标准模式：从数据表选择型号
非标模式：
  UPS型号：[手动输入]
  UPS描述：[手动输入]
  ⚠️ 非标型号不在内置数据表中，请确保参数准确
```

**项目汇总清单**：
- 非标UPS显示橙色"非标"标签
- 型号和描述为可编辑的输入框
- 备注显示"⚠️ 非标型号，请确认参数"

**导出Excel**：
- 类别列显示"UPS（非标）"
- 备注显示"非标型号，请确认参数"

### 2. 电池型号和描述可编辑

**功能说明**：
- 电池型号可手动修改
- 电池描述可手动修改
- 有推荐时默认填入推荐值，无推荐时为空

**界面效果**：
| 类别 | 产品型号 | 产品描述 |
|------|----------|----------|
| 电池 | *[可编辑]* | *[可编辑]* |

**数据结构**：
```javascript
window.projectSummary.battery = {
  model: '',          // 推荐型号
  customModel: '',    // 用户输入的型号（优先使用）
  customDesc: '',     // 用户输入的描述（优先使用）
  // ...其他字段
}
```

### 3. 数据结构

```javascript
window.projectSummary.ups = {
  model: '',
  capacity: '',
  qty: 1,
  price: 0,
  note: '',
  // 新增字段
  isCustom: false,     // 是否非标
  customDesc: '',      // 非标描述（可编辑）
  // 模块化字段
  isModular: false,
  frame: '',
  module: '',
  moduleQty: 0,
  maxModules: 0
}
```

## 业务知识

### 非标UPS场景
- 客户使用其他品牌UPS（华为、艾默生、施耐德等）
- 自研/定制UPS型号
- 不在内置数据表中的新型号

### 注意事项
- 非标型号不在数据表中，无法自动填入参数
- 需要客户手动输入型号和描述
- 电池计算仍可正常进行（基于输入的容量）
