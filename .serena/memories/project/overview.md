# UPS智能选型助手 - 项目概览

（已更新：2026-03-14）

## 基本信息
- **版本**: v1.2.5
- **类型**: 单文件本地Web工具（UPS选型助手.html，约260KB → 320KB）
- **主文件**: `UPS选型助手.html`（HTML + CSS + JS 全部内联）
- **用途**: 销售/技术人员粘贴客户需求，AI自动匹配UPS产品型号
- **线上地址**: https://xiaochuan1989.github.io/-UPS-Selector/

## 核心功能
1. AI智能选型（支持 OpenAI/DeepSeek/Moonshot/Claude 等 API）
2. Excel 导入产品数据（SheetJS解析，IndexedDB持久化）
3. 电池配置计算（铅酸/锂电池/开关盒）
4. 多轮对话追问
5. 导出HTML推荐方案
6. 双栏产品数据库查看器
7. 选型结果对比功能
8. **铅酸电池选型方法2**（输入组数推荐型号）⭐ 新增
9. **电池恒功率数据表** ⭐ 新增
   - 73个电池型号恒功率数据
   - 分类：普通电池、高功率电池、2V电池

## 内置数据
- 179款UPS产品，4个系列：太行UR(21)、昆仑UE(39)、祁连UM(22)、泰山UT(97)
- 73个电池型号恒功率数据（来自A-电池选型模板-A02.xlsm）
- 数据源：常用UPS速查表-V7.5.xlsx

- 锂电池数据：锂电池-选型模板-A00.xlsx

## 部署方式
- **主用**: GitHub Pages（GitHub Actions 自动部署）
- **备用**: Netlify（需手动上传或关联GitHub）
