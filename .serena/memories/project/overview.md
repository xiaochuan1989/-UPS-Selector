- **版本**: v1.4.6（修复传感器量程选择逻辑）

## ⚠️ 核心教训（v1.4.2-v1.4.6 传感器量程Bug）
- **业务逻辑优先**：先搞清楚"应该是什么"，再动手改"怎么实现"
- **主动询问**：遇到业务问题，先问用户正确规则是什么
- **不要猜测公式**：涉及计算公式时，让用户提供原始公式或参考文档
- **停下来问**：用户说"还是错的"时，停下来问清楚，不要继续猜测

## 核心教训（v1.4）
- **数据结构确认**：调用任何函数前，必须确认其返回值结构
- **变量名一致性**：复制代码时确保变量名完全一致（如 BREAKER vs BREAKERS）
- **常量搜索**：添加新常量前，必须搜索是否已存在同名定义
- **const不提升**：被依赖的常量必须定义在调用之前
- **关联位置检查**：修改一处代码，检查所有关联的渲染/导出位置

## 关键公式
| 公式 | 说明 |
|------|------|
| `分开关电流 = maxCurrent / (groups - 1)` | 一组故障时剩余组承担的电流，groups≥2时有效 |
| `传感器量程选择` | 基于【分开关电流】选择，不是单组正常工作电流 |
