### Bug 22-29：本次修复的错误

#### Bug 22: 数据结构访问错误
- **症状**: 电池选型始终返回空，显示"未找到满足要求的电池型号"
- **原因**: `getBatteryRecommendationsByPower` 返回 `{ normal: { suitable: [], all: [] } }`，但代码检查 `recommendations.normal.length`（对象没有length）
- **修复**: 改为 `recommendations.normal.suitable.length`
- **教训**: 调用函数前必须确认返回值结构

#### Bug 23: 变量名拼写不一致
- **症状**: 开关规格始终显示默认值100A/63A，而非正确计算值
- **原因**: `STANDARD_BREAKER_SIZES` vs `STANDARD_BREAKER_SIZES`（BREAKER vs BREAKERS）
- **修复**: 统一变量名为 `STANDARD_BREAKER_SIZES`
- **教训**: 复制代码时确保变量名完全一致

#### Bug 24: 常量重复定义
- **症状**: 控制台报错 "Identifier 'STANDARD_BREAKER_SIZES' has already been declared"
- **原因**: 同一常量在第2376行和第28372行都定义了
- **修复**: 删除重复定义
- **教训**: 添加代码前必须搜索是否已存在同名定义

#### Bug 25: 变量定义顺序问题
- **症状**: 函数调用时常量未定义
- **原因**: `const` 定义的常量不会提升，但函数在前面调用它
- **修复**: 将常量和函数定义移到调用之前
- **教训**: 理解JS变量提升规则，const/let不会提升

#### Bug 26: 开关盒描述不完整
- **症状**: 描述只显示"总开关:630A 分开关:160A"，缺少分开关路数
- **原因**: 保存了`subSwitchQty`字段，但渲染和导出时没有使用
- **修复**: 渲染和导出时添加 `× ${sw.subSwitchQty}路`
- **教训**: 修改代码时要检查所有关联位置

#### Bug 27: 按钮函数名错误
- **症状**: 点击"电池恒功率数据表"按钮无反应
- **原因**: 按钮 `onclick="showBatteryPowerTable()"` 但函数名是 `openBatteryDataTable()`
- **修复**: 统一函数名
- **教训**: 修改后测试每个按钮

#### Bug 28: 开关盒数量逻辑错误
- **症状**: 开关盒数量显示为电池组数
- **原因**: `qty = totalGroups` 应该是 `qty = upsNum`
- **修复**: 1台UPS配1个开关箱/柜
- **教训**: 理解业务规则后再编码

#### Bug 29: 功能被误删
- **症状**: 电池计算方法一和锂电池功能丢失
- **原因**: 重构时删除了HTML面板，但函数代码还在
- **修复**: 创建独立的"电池计算(方法一/锂电)"界面
- **教训**: 重构时保留原有功能

## v1.4 核心教训总结

### 犯错的根本原因
1. **未确认数据结构**：凭猜测假设函数返回值
2. **变量名拼写错误**：复制代码时未检查一致性
3. **未搜索现有定义**：直接添加新常量导致重复
4. **不理解JS提升规则**：const不会提升
5. **修改不完整**：只改了一处，遗漏关联位置

### 改进方法（必读）
| 步骤 | 说明 |
|------|------|
| **搜索优先** | 修改代码前，先用 `grep` 搜索相关定义 |
| **结构确认** | 调用函数前，确认其返回值结构 |
| **一致性检查** | 复制代码后，检查变量名是否一致 |
| **完整性检查** | 修改一处代码，检查所有关联的渲染/导出位置 |
| **测试验证** | 每次修改后，刷新页面测试所有按钮 |

## 开发注意事项
1. **函数定义顺序**: 初始化阶段调用的函数必须定义在调用位置之前
2. **file://协议**: 双击HTML使用，IndexedDB可用但有限制
3. **单文件约束**: 所有代码内联，修改时注意不要破坏script标签结构
4. **同步index.html**: 每次修改后必须同步
5. **浏览器测试**: 功能完成后用浏览器验证
6. **语法检查**: 用Node.js `new Function()` 检查JS语法
7. **部署优先**: GitHub Pages（免费无限）> Netlify（有限额）
8. **自我验证清单**: HTML表格列数=渲染函数列数、输入字段=处理变量、Excel数据=代码数据
