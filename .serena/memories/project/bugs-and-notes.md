# 已修复的Bug与开发注意事项

（已更新：2026-03-17）

## 已修复Bug

### 1. IndexedDB 持久化初始化顺序Bug（2026-03-09）
- **症状**: 刷新页面后导入数据丢失，控制台报错 `Cannot access 'db' before initialization`
- **原因**: `loadProductsFromDB()` 在IIFE中被调用时函数尚未定义
- **修复**: 改用 `DOMContentLoaded` 延迟调用
- **关键**: IndexedDB相关函数必须在DOMContentLoaded回调之前定义

### 2. 开关盒计算JS语法错误（2026-03-12）
- **症状**: 按钮点击无反应
- **原因**: 修改代码时出现语法错误（缺少括号、变量名拼写等）
- **修复**: 仔细检查代码语法，每次修改后浏览器测试

### 3. Netlify部署配置错误（2026-03-12）
- **症状**: Netlify报错 "deploy directory is not a directory"
- **原因**: `netlify.toml` 中 `publish` 配置为文件而非目录
- **修复**: 改为 `publish = "."`，添加重定向规则

### 4. 铅酸电池数据不完整（v1.3.0, 2026-03-14）
- **症状**: 缺少2V电池，放电时间只有部分
- **修复**: 完整遍历所有时间列，正确识别所有电池型号

### 5. 下拉框选项与数据不匹配（v1.3.0）
- **修复**: 根据实际数据动态生成下拉框选项

### 6. GitHub Pages 未更新（v1.3.0）
- **原因**: index.html未同步
- **修复**: 每次推送后同步更新index.html

### 7. HTML标签语法错误（v1.3.0）
- **原因**: `<\label>` 错误闭合标签
- **修复**: 检查HTML标签语法

## 开发注意事项
1. **函数定义顺序**: 初始化阶段调用的函数必须定义在调用位置之前，或用DOMContentLoaded延迟
2. **file://协议**: 双击HTML使用，IndexedDB可用但有限制
3. **单文件约束**: 所有代码内联，修改时注意不要破坏script标签结构
4. **同步index.html**: 每次修改后必须同步
5. **浏览器测试**: 功能完成后用浏览器验证
6. **语法检查**: 用Node.js `new Function()` 检查JS语法
7. **部署优先**: GitHub Pages（免费无限）> Netlify（有限额）
8. **自我验证清单**: HTML表格列数=渲染函数列数、输入字段=处理变量、Excel数据=代码数据
