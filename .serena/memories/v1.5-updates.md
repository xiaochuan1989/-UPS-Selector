## v1.5.4 Bug修复（2026-03-31）

### 问题描述
当电池没有推荐型号时，电池架描述不体现连接铜排信息；单组电池时铜排规格错误

### 根本原因
1. `var batteryResult` 只在 `if (foundBattery)` 块内声明，else 分支未定义
2. **错误理解业务逻辑**：认为"没有分开关就不需要铜排"，实际上铜排是电池架连接导体，与分开关是独立概念

### 错误代码
```javascript
// 之前：只有 groups>=2 才有铜排
cableAmp: rackCable === 'yes' && groups >= 2 ? subSwitchSize + 'A' : ''
// 单组电池时，铜排为空，但实际应该用主开关规格
```

### 正确理解
| 场景 | 铜排电流规格 | 说明 |
|------|-------------|------|
| 单组电池 (groups=1) | 主开关规格 (mainSwitchSize) | 所有电流都通过主开关 |
| 多组电池 (groups≥2) | 分开关规格 (subSwitchSize) | 铜排连接电池到分开关 |

### 正确代码
```javascript
// 单组用主开关规格，多组用分开关规格
cableAmp: rackCable === 'yes' ? (groups >= 2 ? subSwitchSize : mainSwitchSize) + 'A' : ''
```

### 经验教训
- **业务逻辑优先**：写代码前先确认"应该是什么"，不是"我觉得是什么"
- **主动询问**：涉及电气/工程等专业领域时，先问用户正确规则，不要凭常识猜测
- **停下来问**：用户说"不对"时，第一时间问清楚，而不是继续猜
- **理解本质**：分开关是配电保护，铜排是电池连接导体，是两个独立概念

### 修复内容
| 文件 | 函数 | 修复 |
|------|------|------|
| `UPS选型助手.html` | `calcAllBatteryConfig()` | 修复 cableAmp 计算逻辑 |

## v1.5.1 Bug修复（2026-03-24）

### 问题描述
项目汇总清单的"清空"按钮点击无反应，同时影响Excel导出功能。

### 根本原因
`clearProjectSummary()` 和 `importUpsFromResult()` 函数访问了HTML中从未定义的DOM元素。

### 经验教训
```
⚠️ 修改函数时，必须确认其中引用的DOM元素确实存在
   - 搜索 getElementById 调用，验证元素ID在HTML中存在
   - 不能假设"以前能用"就永远能用
   - 清理旧版本遗留的无效代码引用
```

## 主要变更

### 1. 新增电池架功能

**功能说明**：
- 项目汇总清单新增"电池架"行
- 电池架容量 = 电池节数（cellsPerGroup）
- 电池架数量 = 电池组数 × UPS台数
- 支持选择"是否含连接铜排/电缆"

**描述格式**：
- 不含铜排：`安装32节/架，电池型号：12V100AH`
- 含铜排：`安装32节/架，电池型号：12V100AH，含100A连接铜排或电缆`

**铜排电流规格**（已修正）：
- 单组电池时：主开关规格 (mainSwitchSize)
- 多组电池时：分开关规格 (subSwitchSize)

### 2. 新增电池开关选项

**功能说明**：
- 统一计算面板新增"电池开关"下拉选项
- 选项值：合资开关（施耐德/ABB/西门子等）、国产开关（良信/正泰/天正/德力西等）

## 业务知识（重要修正）

### 电池架连接铜排 vs 分开关

| 误解 | 正确理解 |
|------|----------|
| 铜排是分开关的配套 | 铜排是电池架本身的连接导体 |
| 没有分开关就不需要铜排 | 不管几组电池，铜排都是连接电池端子的必需导体 |

**铜排规格计算**：
- 单组电池：全部电流流经主开关，铜排与主开关配套
- 多组电池：铜排连接电池到分开关，铜排与分开关配套
