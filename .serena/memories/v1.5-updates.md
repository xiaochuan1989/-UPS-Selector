## v1.5.1 Bug修复（2026-03-24）

### 问题描述
项目汇总清单的"清空"按钮点击无反应，同时影响Excel导出功能。

### 根本原因
`clearProjectSummary()` 和 `importUpsFromResult()` 函数访问了HTML中从未定义的DOM元素：
- `summary-ups-model`
- `summary-ups-cap`
- `summary-ups-qty`
- `summary-ups-code`
- `summary-ups-price`

这些元素ID可能是旧版本遗留代码，当前HTML中不存在，导致 `getElementById` 返回 `null`，后续访问 `null.value` 报错。

### 修复内容
| 文件 | 函数 | 修复 |
|------|------|------|
| `UPS选型助手.html` | `clearProjectSummary()` | 删除对不存在DOM元素的访问 |
| `UPS选型助手.html` | `importUpsFromResult()` | 删除对不存在DOM元素的访问 |
| `index.html` | 同上 | 同步修复 |

### 提交记录
- `4fa41ee` - 初步尝试添加缺失字段
- `66140d7` - 根本修复：删除对不存在元素的访问

### 经验教训
```
⚠️ 修改函数时，必须确认其中引用的DOM元素确实存在
   - 搜索 getElementById 调用，验证元素ID在HTML中存在
   - 不能假设"以前能用"就永远能用
   - 清理旧版本遗留的无效代码引用
```

## 主要变更

### 1. 新增电池架功能

**功能说明**：
- 项目汇总清单新增"电池架"行
- 电池架容量 = 电池节数（cellsPerGroup）
- 电池架数量 = 电池组数 × UPS台数
- 支持选择"是否含连接铜排/电缆"

**界面位置**：
统一计算面板 → 电池架含铜排/电缆 选项

**描述格式**：
- 不含铜排：`安装32节/架，电池型号：12V100AH`
- 含铜排：`安装32节/架，电池型号：12V100AH，含100A连接铜排或电缆`

**铜排电流规格**：
- 来自分开关电流对应的标准断路器规格（subSwitchSize）
- 例如：分开关电流95A → 选大一号规格100A

### 2. 新增电池开关选项

**功能说明**：
- 统一计算面板新增"电池开关"下拉选项
- 选项值：合资开关（施耐德/ABB/西门子等）、国产开关（良信/正泰/天正/德力西等）
- 开关类型显示在电池开关箱/柜描述中

**UI设计**：
- 开关类型旁边添加❗提示图标
- 鼠标悬停显示品牌说明

### 3. 序号列和样式优化

**序号列**：
- 项目汇总清单添加序号列（第一列）
- 导出Excel同步显示序号

**类别换行样式**：
- 导出Excel中类别列文字换行显示

**备注列边框样式**：
- 未输入密码时备注列也应用边框样式

### 4. 导出Excel样式完善

**新增样式**：
- 标题行：深蓝色背景、白色粗体字
- 表头行：浅蓝色背景、居中对齐
- 数据行：白色背景
- 分类背景色：UPS蓝色、电池绿色、开关黄色、监控橙色、电池架粉色
- 合计行：浅灰色背景、加粗

## 业务知识

### 电池架计算规则
- 电池架容量：根据电池组配置的节数决定
- 电池架数量：每电池组配一个电池架
- 连接铜排：选择"含"时，描述中体现电流规格

### 电池开关品牌
| 类型 | 品牌 | 说明 |
|------|------|------|
| 合资开关 | 施耐德/ABB/西门子等 | 国际知名品牌 |
| 国产开关 | 良信/正泰/天正/德力西等 | 国产品牌 |

### 示例
- 配置：2台UPS，每台3组电池，32节/组
- 电池架数量 = 3 × 2 = 6架
- 描述：安装32节/架，电池型号：12V100AH，含100A连接铜排或电缆
