# 归档说明

本目录用于把根目录中的历史资料和待清理文件分区放置，避免干扰当前 UPS 智能选型助手主线开发。

## 目录分区

- `历史文档/`：旧备份页面、历史参数文本、早期生成脚本、旧电池数据等资料。
- `历史数据源与模板/`：旧 Excel / xlsm 数据源和业务模板。当前自动测试仍使用的 `常用UPS速查表-V7.5.xlsx` 保留在项目根目录。
- `历史测试数据/`：早期测试数据和试验脚本。
- `垃圾待清理/`：旧部署输出、旧会话、旧评估目录、旧本地缓存等。这里是“确认后可删除”的暂存区，不是正式项目输入。

## 当前主线

正式产品入口仍是项目根目录的 `index.html`。发布和验证只依赖根目录主文件、`dev_scripts/`、`.github/`、`netlify.toml`、README 和开发文档。
